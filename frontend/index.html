Smartphone-as-a-Sensor (SaaS) • 108 Driver App vs Legacy Dedicated Hardware

Instead of installing costly GPS tracker boxes (SIM808/NEO-6M) into every ambulance vehicle, the driver or EMT operates an official Karnataka 108 Arogya Kavacha Mobile Application. Telemetry flows via 4G/5G directly into the Mysuru Central Traffic Police (MCTP) Command Cloud.

01 • AUTHENTICATION

Driver Login & Dispatch ID

Driver enters Employee ID (DRV-MYS-108) and 108 Incident Ticket ID. Eliminates misuse by unauthorized drivers speeding without patients.

02 • TRIAGE SELECTION

Medical Urgency Tier

Paramedic chooses Triage level: P1 Code Red (Trauma/Cardiac → Cascading Green Wave) vs P3 Blue (Routine → Standard traffic).

03 • CLOUD BROKER

MCTP Police Control Room

Central server monitors city-wide map and issues low-latency preemption overrides to roadside signal microcontrollers.

04 • ZERO EXTRA COST

₹0 Vehicle Hardware Overhead

Utilizes phone’s internal dual-frequency GPS + NavIC satellite receivers. Zero installation downtime, zero vehicle battery drain.

Coordinated Cascading Green Wave Algorithm

A single preempted intersection is just a local override. A true Green Corridor synchronizes consecutive traffic signals along the route based on real-time vehicle kinematics:

Corridor Stage Distance to Junction Traffic Signal Action Civilian Traffic Handling
Upstream Detection > 250m Normal cycle continues; preempt request queued Civilian vehicles flow normally; signal timings logged
Advance Clearance 150m – 250m Cross-traffic transitions to Amber → Red; main corridor turns Green Standing queue cleared; vehicles ahead of ambulance exit intersection
Corridor Lock 0m – 150m Green light held open; pedestrian phases suppressed Ambulance experiences zero stop-and-go delays (true non-stop transit)
Downstream Cascading Approaching next junction Next junction initiates clearance before ambulance clears current one Creates a rolling wave of green lights along the entire emergency route
Cycle Recovery Vehicle clears box (> 25m past) Signal returns to normal cycle gracefully; accumulated queue dissipated Cross-street given compensated green time to prevent gridlock
